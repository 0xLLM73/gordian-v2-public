# Support

Gordian v2 is shared as an experimental, unhosted codebase. There is no hosted service, production support channel, or uptime commitment for this repository.

## Before Opening An Issue

Please check:

- [docs/PUBLIC_STATUS.md](docs/PUBLIC_STATUS.md) for the current public status;
- [docs/OPEN_SOURCE.md](docs/OPEN_SOURCE.md) for release and credential-cleanup guidance;
- [docs/SECURITY_NOTES.md](docs/SECURITY_NOTES.md) for Telegram and runtime-secret risks;
- [docs/CODEBASE_MAP.md](docs/CODEBASE_MAP.md) for the current codebase layout.

## Security Issues

Do not report sensitive vulnerabilities or possible credential exposure in public issues. Use GitHub private vulnerability reporting if it is enabled for this repository, or contact the maintainer privately.

## Telegram Issues

The original Telegram bot has been deleted, and Telegram features are disabled by default. Reports involving real Telegram accounts should be reproducible with throwaway Telegram resources only.
